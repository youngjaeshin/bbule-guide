# 지휘관 초상화

2026-11-02 사용자가 제공한 목록 화면 3장에서 35명의 초상화만 크롭했다. 수량·레벨·이름·등급 아이콘을 제외한 얼굴 영역을 원본 100×100 픽셀로 보존했다. 원본 사본, 크롭 좌표와 해시는 `output/commander_portraits/20261102/` 및 `commander_portraits.json`에 기록했다.

기존 34명의 이름·등급·능력치·스킬은 변경하지 않았다. 화면 표기와 기존 이름이 다른 언더더씨/언더씨, 사오 일나런 홀트/웩스 홀트, 골드루그/골그루트는 기존 가이드 이름을 유지하고 원본 표기를 초상화 메타데이터에 따로 기록했다.

기존 목록에 없던 실러캔스는 이름·초상화만 추가했다. 등급은 사용자 정정 및 원본의 녹색 이름 확인에 따라 훌륭함이며 능력치, 성별, 스킬 수치는 채우지 않았다. `dataStatus: identity_and_portrait_only`로 구분한다.

`build_commander_tab.py`의 `apply_commander_portraits`가 기존 정보에 이미지 경로를 연결한다. 기존 웹의 수동 수정 내용을 보존하면서 이미지만 재연결하려면 `python3 scripts/rebuild_commander_portraits.py`를 실행한다. 전체 지휘관 탭 빌더를 다시 실행할 필요는 없다.

`python3 scripts/verify_commander_portraits.py`는 원본 픽셀 일치, 35개 이미지 연결, 기존 34명의 비이미지 필드 보존, 다른 완료 데이터 및 경험치 상수 보존을 검사한다.

등급 판정은 이름 글자색을 기준으로 흰색=평범함, 녹색=훌륭함, 빨강=영웅이다. 원본3장·35명을 재대조해 평범함13/훌륭함12/영웅10을 확인했다. 실러캔스를 영웅으로 입력했던 오류를 수정했으며 사진 크롭·기존 능력치·스킬은 변경하지 않았다. `commander_portraits.json`의 검증된 grade가 이미지 재연결 때도 적용되어 오류가 재생성되지 않도록 했다.
