# 용병 전체 카드 이미지 교체

용병556명의 이미지를 실제 용병도감의 전체 카드160×222 PNG로 교체했다. 등급·테두리·게임 내 이름·레벨 줄을 포함한다. 원본 페이지와 이름/등급 대조를 마친 카드만 연결했으며 이전 이미지556개는 보존했다.

클릭 직후 공격/점프 상태를 피하도록 이동 후 대기해 촬영했다. E드라코의 카드 안에 들어온 자세를 확인했다. 일부 대형 모델이 게임 원본 자체에서 프레임을 넘는 경우는 원본 테두리를 기준으로 크롭하고 그림을 합성하거나 모델만 축소하지 않았다.

`mercenary_card_portraits.json`이 새 이미지와 원본 좌표·해시를 기록한다. `mercenary_capture_overrides.json`의 portrait_manifest가 이 파일을 참조하므로 재생성 후에도 유지된다. 기존 스킬2780개·패시브·수치 및 다른 탭의 데이터는 변경하지 않았다. 시뮬레이터의 이미지 참조도 갱신했고 전체 카드를 자르지 않도록 contain 표시를 유지한다.

검증: 원본556개 정확한 픽셀 크롭·육안 검토, 이전 이미지 보존, 용병/시뮬레이터 비이미지 필드 보존PASS. 브라우저 새 이미지556개 로딩과 E드라코·X아딜리야·P유나 목록/상세 표시PASS. JSON/inline 동기화·strict 용병 스킬 검사PASS.

원본 및 세부 검토는 비공개 로컬 `output/mercenary_card_refresh/20261102/`에 보존했다. 원본 전체 스크린샷은 배포에 포함하지 않는다.
